# 从 PVF 准备地下城翻牌

`BuildCards` 读取普通地下城定义、资源候选和装备生成参数，生成免费翻牌、付费翻牌和挑战翻牌目录。普通付费翻牌继续校验原代码冻结的 8,014 个常规装备编号。符合原始类别和权重条件的宠物及其装备候选与这些编号合并。准备器按游戏的等级窗口及难度档位生成原候选池。特定奖励使用地下城脚本的 `[item]` 门槛，分组奖励读取普通付费翻牌资源中已生效的配置。冻结的候选、权重和收据哈希由运行时使用。

使用项目原始 PVF 独立生成的目录与 C# 导出逐字段对比。免费和付费翻牌分别匹配 `67E46C3555866D08ABC1ED254882A8D9C0BC5917850E2AED5D934650D4F24C30` 和 `A5C5DA47845533E14128A57863BB458DE1DF21F958B286429E7D8C12F3035FF4`。同一输入包含 8,055 个候选、1,017 个付费池、两组付费分组和 14 条挑战翻牌记录。挑战记录按地下城编号和阶段排序，比较时用同一键校对 C# 目录。

来源见 [DungeonCardExport](../../../tools/catalog-export/DungeonCardExport.cs) 和 [旧端固定装备编号](../../../../s9a1/Server/src/Serve100.Infrastructure/Resources/LocalDungeonPaidCardEquipmentIds.cs)。
