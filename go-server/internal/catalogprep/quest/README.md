# 原始 PVF 任务和成长目录

本包从同版本 `Script.pvf` 生成任务、成长道具、装扮、战令和随机伪装目录。运行时通过 Go 资源包读取目录，任务收据保留原来的正文和场景哈希。

- `Build` 生成普通任务、全部任务券的任务资格、过去任务和城镇范围。它复核问答、通信器、有序子任务和隐藏 NPC 的场景依赖，并分别返回接受奖励、任务消耗材料和完成奖励的模板编号，供主目录统一物化。
- `BuildGrowth` 解析经验书和经验药、升级券、胶囊、11 类任务券、传送、宠物经验、装备槽及徽章合成，以及装扮染色、属性变更、打孔、特效、分解、合成和转换。它也向总目录提供旧服预先解析的疲劳药和传送药编号。装扮和堆叠道具按压缩块顺序读取。拥有容量上限的旧目录仍以模板编号顺序决定收录对象。
- `BuildBattlePass` 生成 100 级奖励、84 项任务和奖励模板。`BuildDisguise` 验证原道具取得资格与 54 个随机形态。

使用本项目的原始 PVF 和旧 C# 目录独立比对了 2,905 条普通任务、2,905 条任务券资格、956 条过去任务、61 条城镇范围，及成长和装扮分区。运行时所需的持久化状态仍由原来的 Go 任务、商店和游戏协议处理程序消费。

来源见 [旧任务导出](../../../tools/catalog-export/QuestExport.cs)、[旧成长导出](../../../tools/catalog-export/QuestGrowthExport.cs)、[旧装扮导出](../../../tools/catalog-export/QuestAvatarExport.cs) 和 [旧战令导出](../../../tools/catalog-export/QuestBattlePassExport.cs)。
