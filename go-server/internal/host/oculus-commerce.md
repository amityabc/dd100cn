# 洞察之眼商人

频道 63 的角色入口要求 100 级、已初始化和已完成任务 12167。C21 买入、C22 卖出、C23 或 C217 修理，需要在尚未超时的洞察之眼副本中完成加载。商人和商店号由原 PVF 的实际副本绑定给出。Go 在商人操作前核对入场收据、对时限产生影响的击杀收据，以及当前挑战中指定怪物的营救收据。营救后同一区域仅营救格可交易，其余区按原服规则开放。继续挑战沿用原营救凭据，但使用当前场景的加载及位置。

买卖和修理走原库存事务。该事务在回放应答前重查当前场景和凭据，修理收据附带场景代次、商人和营救击杀凭据。普通副本仍由清图、当前房间及商人资源共同判定。C707 普通商店计数在原服排除洞察之眼副本。

资源导出增加 `Commerce.OculusPeers`。更新服务时需要用同一 PVF 重新运行 `tools/export-characters.ps1`，再使用匹配的 Go 目录加载资源。
