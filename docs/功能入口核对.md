# 原版功能索引与 Go 入口核对

[原版功能索引](../s9a1/Docs/Features.md) 有 73 行、72 个唯一功能 ID。`DUNGEON-WISDOM` 的两行共用一个 Go 入口。下表仅记录固定原 C# 程序现有行为的 Go 入口及范围。客户端流程、PostgreSQL 事务恢复和原版已列出的资源缺口分别验收。[原程序基线](../baseline/README.md)

原服的普通队伍和洞察按单成员处理，自由与排位大厅内的练习使用场景规则和 AI 对手。两账号独立连入和同账号会话替换已有回环证据。跨机同城互见、真人组队和同副本同步缺少同版本双方报文，尚无 Go 实现。[入口合同](../s9a1/Docs/Modules/Entry.md) · [洞察协议](../s9a1/Docs/Protocols/Oculus.md) · [隔离连接用例](../go-server/internal/multiplayer/live_test.go)

## 被动投影

- 普通背包在本次已提交获取物品时用 N14 增量刷新，重复使用旧槽时先给该槽发送删除标记，再写入钱包和新增物品。移动、仓库转移和扩包继续按原容器路径显示。
- BUFF 登记在准备完成时用 N1361 恢复选择。装备位置或已发布库存版本变化时按当前登记实例发 N1360，C19/C20 的重复应答也依照原投影条件。
- 晶之契约在决斗场恢复时先发普通背包，再发 N889。普通城镇的初次和返回恢复沿用现有 N889 时序。
- 选角读取角色保存的宠物实例并为当前会话登记饱食度时钟，首次场景就绪后进入对应模式。普通副本换房保留已经加载的耗粮状态，剧情层和武斗大会暂停。C44 自己发送最终饱食度，普通包按已提交变化送 N103。连接释放时按该 owner 和 epoch 冻结原时钟，旧连接关闭不会写入新会话的宠物状态。[选择角色](../go-server/internal/host/game.go) · [时钟](../go-server/internal/host/commerce_pet_clock.go) · [关闭归属向量](../go-server/internal/storage/pet_release_test.go)
- 首次 C120/C143 按旧存档数值初始化尚未初始化的角色，使用原一级 SP 与起始技能作为缺省值。每日任务在这次同步按北京时间 06:00 刷新，首次为旧档登记日期时保留原清除标记。教学自动进场也启动原在线幸运值计时，红玉 C72 重试按原 06:00 疲劳边界作资格判定。
- GM 离线投递每两秒处理一次，每批最多 16 条。目标角色已完成初始化并处于城镇就绪阶段时，队列才尝试递送。
- 正常启动从 PostgreSQL 一次读取全库现持有模板 ID，范围包括普通、武器和共享库存、角色特殊资产及尚未领取的邮件附件。匹配原 PVF 的物品规则在服务监听前补入内存目录。模板 100050017、100050022、100050023 逐字段与旧 C# 对照，强化金币分别为 54,128、73,013、125,888，重量均为 1,400，邮箱资格和品级规则一致。43,408 条基础城镇商品保持原样。[启动准备](../go-server/cmd/serve100/main.go) · [既存物品绑定](../go-server/internal/catalogprep/owned.go)
- C176 `//item` 验证租约和 GM 账号权限后读取匹配 PVF，生成授权授予及其关联规则。准备成功才发布新的不可变目录。其他已受理请求各自保留帧快照，GM 邮件可按需准备可作为普通附件的物品。[在线发布](../go-server/internal/host/gm_catalog.go) · [邮件入口](../go-server/internal/host/operator_mail.go)
- 账号服务 N897 可在下一次输入处理到期和每日使用次数切换。金币扩张 N938、装扮能量 N1929 与战令的选角、进城和后续变化使用相应的独立投影。
- C23 七字节自动修理按旧端顺序回复修理结果、普通背包 N13 和穿戴 N14。手动修理继续根据已存在的宠物及徽章库存投影对应列表。
- C494、C777 和 C1880 只在城镇就绪后执行，C494 另按原普通城镇资格检查。C777 的阶段拒绝应答保留当前角色的职业替换次数。

同槽获取标记及洞察营救位置已有小型离线向量。Go 已从匹配 PVF 重建 C507 的 218 个任务券模板并核对原资源目录。客户端应答顺序、提交后重放以及全量跨版本旧档仍需专项验收。[任务券编译](../go-server/internal/catalogprep/quest/) · [任务券入口](../go-server/internal/host/quest_ticket.go)
