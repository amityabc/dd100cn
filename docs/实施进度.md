### 同一组回环请求

两端均使用相同驱动，在单连接内依次请求。各项预热 1 次、测量 100 次。旧服 C35 没有自身成功 ACK，以后续 C1715 为计时边界，并回读存档验证了 101 次位置版本递增。

| 操作 | 旧 C# P95 / P99 | Go 首轮 P95 / P99 | Go 复测 P95 / P99 |
| --- | --- | --- | --- |
| C8 空角色列表 | 15.435 / 16.655 ms | 2.569 / 2.800 ms | 1.210 / 1.429 ms |
| C679 空名单探测 | 10.078 / 12.203 ms | 0.421 / 0.481 ms | 0.339 / 0.385 ms |
| C1715 心跳 | 9.102 / 10.064 ms | 0.402 / 0.491 ms | 0.385 / 0.445 ms |
| C35 保存位置加 C1715 | 25.510 / 26.590 ms | 4.427 / 4.607 ms | 1.972 / 2.175 ms |

Go 两轮位置测试均回读了 101 次提交。以上均为单机回环上的顺序请求。首批 Go 游戏服务的编译器缓存为空时构建用时 22.281 秒，原样重建 0.925 秒，改一处玩法后 2.165 秒。第二次使用独立空缓存，分别为 19.210、0.885、1.757 秒。旧服的 77.175 秒包含完整正式构建，两边玩法覆盖与构建范围有区别。多人容量仍待同场景压测。[旧服测量数据](../baseline/results.json) · [Go 测量数据](../baseline/go-results.json) · [构建复测](../baseline/measure_go.py)
