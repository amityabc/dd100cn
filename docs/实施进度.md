### 本轮逻辑迁移

以本项目用固定 S9A1 源码、匹配 PVF 和 SQLite 存档构建并运行的原 C# 程序为基线。下面记录已接入的 Go 行为、离线对照和历史回放。原客户端实机验收与跨机同场的协议、实现工作分别记录。[原程序基线](../baseline/README.md)

同一份 `Script.pvf`、`sk.dat` 和客户端 profile 分别交给 Go 和旧 C# 生成两组资料。整份玩法目录 22 个顶层字段、GM ZIP 的 260 个文件均已比对，差异均为 **0**。6 张按唯一键查找的表按键比对，两组 NPC 可见性名单按成员比对，随机掉落、奖励顺序和其余数组逐项保序。服务端也已用运行时加载器读回两份 Go 生成物。本机生成玩法目录用时 57.399 秒。Go 玩法 JSON 的 SHA-256 为 `142ED1302CF10F4447CF29CBEFA2B1A07143297681C81F86298DC901B072D974`，GM ZIP 为 `F2714F70C128C8404BB7D45E7FDE6A634D80F4AC3EABB4B75DADB3368250DF71`。[资源编译器](../go-server/cmd/prepare-catalog/) · [结构比对程序](../go-server/tools/compare-catalog.py)

旧 SQLite 存档的 v1～v34 升级已移入 Go 导入器。选取 v3 武器与 WAL、v34 历史收据、洞察 v14/v23 和水晶 v26/v27，使用旧 C# 与 Go 分别升级同一快照，六条路径均通过逐表行数和内容摘要对照。旧库保留原始摘要，升级只作用在项目内的一次性副本。[旧档导入说明](../go-server/internal/storage/README.md)

原版发行程序生成的 v35 空服存档，以及在其副本上把当前余额改为 830,102 的样本，分别导入了隔离的 PostgreSQL 数据库中的两个账号。每个账号连续启用两次，均可回读原始发行收据、来源摘要和各自的当前余额。两个账号的收据都记录首次发行的 1,000,000 点券和 0 个角色。副本额外保存的中文键和含零字节的值也能按账号原样回读。[发行样本与回归](../go-server/internal/storage/legacy/foundation_test.go) · [账号发行记录](../go-server/internal/storage/foundation_state.sql)

### 同一组回环请求

两端均使用相同驱动，在单连接内依次请求。各项预热 1 次、测量 100 次。旧服 C35 没有自身成功 ACK，以后续 C1715 为计时边界，并回读存档验证了 101 次位置版本递增。

| 操作 | 旧 C# P95 / P99 | Go 首轮 P95 / P99 | Go 复测 P95 / P99 |
| --- | --- | --- | --- |
| C8 空角色列表 | 15.435 / 16.655 ms | 2.569 / 2.800 ms | 1.210 / 1.429 ms |
| C679 空名单探测 | 10.078 / 12.203 ms | 0.421 / 0.481 ms | 0.339 / 0.385 ms |
| C1715 心跳 | 9.102 / 10.064 ms | 0.402 / 0.491 ms | 0.385 / 0.445 ms |
| C35 保存位置加 C1715 | 25.510 / 26.590 ms | 4.427 / 4.607 ms | 1.972 / 2.175 ms |

Go 两轮位置测试均回读了 101 次提交。以上均为单机回环上的顺序请求。首批 Go 游戏服务的编译器缓存为空时构建用时 22.281 秒，原样重建 0.925 秒，改一处玩法后 2.165 秒。第二次使用独立空缓存，分别为 19.210、0.885、1.757 秒。旧服的 77.175 秒包含完整正式构建，两边玩法覆盖与构建范围有区别。多人容量仍待同场景压测。[旧服测量数据](../baseline/results.json) · [Go 测量数据](../baseline/go-results.json) · [构建复测](../baseline/measure_go.py)

### 当前交付边界

Go 服务独立监听原生频道和游戏 TCP，同时可启用认证网关。本机旧入口使用本机账号，认证入口按登录凭据分配各自账号。旧 GM 启动器仍传固定账号 `local`。原客户端实机操作、正式切换和全量旧库启用尚未执行。新增的双机同场范围另有协议采样和实现工作。[开发与运行](../go-server/README.md) · [外部工具字段与验收状态](工具交互对照.md) · [全量范围](全量迁移清单.md)
